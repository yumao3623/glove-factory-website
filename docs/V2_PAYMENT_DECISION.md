# 2.1 支付决策

**选择 PayPal 中国企业卖家账户及全球收单，配合“先询价、确认报价后付款”。当前收款关闭。**

2026-09-18 用户确认使用江山美来服装厂营业执照，由经营者/法人认证；随后说明资料需要向阿姨取得，开户暂时不能完成。因此本次部署网站与报价功能，不登记虚假商户资料，不把本地测试或代码完成算作正式支付上线。

## 便利性判断

| 方案 | 与本项目的匹配 | 本次决定 |
| --- | --- | --- |
| PayPal 中国企业卖家账户＋全球收单 | 面向国外买家的网站付款，有标准 Checkout、REST API 和回调方案；企业卖家可申请跨境收款至境内指定账户 | 首选。适合先把独立站报价付款路径接通 |
| 万里汇 WorldFirst B2B | 线上申请多币种跨境收款账户，适合对公转账收款、资金管理和人民币结算 | 保留为大额 B2B 转账及结算备选 |
| 连连支付 | 跨境收单备选，需单独确认商户方案、市场和接口条件 | 本次不并行接入 |

“更方便”是基于本站付款方式和标准接口的产品判断，不是开户一定获批或费率最低的承诺。PayPal 中国当前同时提供个人和企业卖家入口；本项目选择企业路径是因为用户已经选择工厂经营主体。中国大陆银行卡能否绑定、指定结算账户的开户名与主体要求，必须按实际认证结果确认。

收单费、币种转换费、结汇费和提现费是不同费用，不能用人民币结算优惠费率替代整笔收款成本。以正式开户协议和当时费率为准。

## 已实现与开启条件

后台可创建包含买家、行项目、币种、有效期、运费、税费和已确认商业条款的报价。买家通过私有链接或已验证的对应账户查看；服务器重新核对金额，未接受条款、报价失效或取消时不创建支付。管理员可以取消未付款报价。

已实现 PayPal 创建订单、返回捕获、签名验证、金额/币种校验、幂等入账和全额退款状态核对。所有这些均不能替代真实商户测试。

当前 `PAYPAL_CHECKOUT_ENABLED=false`。用户完成开户后还需：配置沙盒凭据和 webhook ID，完成成功/取消/重复回调/退款验收，确认生产收单与境内结算账户，再配置生产凭据、生产 webhook 和开启开关。密码、证件、银行卡和协议确认由经营者本人在官方页面完成。
