## Asset boundaries

### `REF_*` = DESIGN REFERENCE ONLY

Every file in `01_REFERENCES/` is marked `REFERENCE_ONLY` and `DO_NOT_USE_AS_SITE_CONTENT`.

Use these screenshots only to study:

- composition
- image density
- typography hierarchy
- whitespace
- page rhythm
- navigation density

Absolutely do not copy or reproduce:

- competitor imagery
- competitor wording or claims
- logos
- branding
- exact page layouts

`REF_05_dents_desktop.png` includes the source site's cookie modal because no cleaner Dents desktop capture exists in the reviewed evidence. Ignore the modal and do not reproduce it.

### `CONTENT_*` = REAL FACTORY CONTENT ASSETS

Files in `02_CONTENT_PRODUCTS/` and `03_CONTENT_FACTORY/` are the real reviewed factory imagery that Stitch should actually use in the new website design.

These `CONTENT_*` images are for **LOCAL VISUAL DESIGN ONLY**. Publication permission remains pending where applicable. Do not treat the images as proof of certification, capacity, composition, performance, customer recognition, or any other product/factory claim.

Do not edit, retouch, crop into new source files, or generate AI replacement imagery for these assets. Do not use any rejected, watermarked, Chinese promotional, marketplace-poster, screenshot, or Frozen/Elsa/Disney imagery.

## Stitch task target

**FIRST STITCH GENERATION MUST BE:**

**ONE PAGE ONLY**

**1440PX DESKTOP HOMEPAGE**

Do **not** generate:

- mobile
- design-system board
- logo
- bridal collection page
- other pages
- additional screens

The first generation solves only the desktop homepage visual direction.

## Image usage target

- Use approximately **10–16 meaningful `CONTENT_*` image placements** across the homepage.
- Product photography must dominate the page.
- Use the five product families for visual wayfinding and category rhythm.
- Use factory imagery only in a supporting B2B trust/process band, never as hero photography.
- Do not make a huge-typography page with empty whitespace and only a few cards.
- Keep the page sourcing-forward: clear family navigation, comparison-friendly product frames, and a visible RFQ/enquiry path.

## Hard exclusions

- No competitor asset may appear as site content.
- No competitor logo, copy, branding, or exact layout.
- No mobile competitor screenshots.
- No blank/loading or hydration/error screenshot.
- No marketplace UI screenshot used as `CONTENT`.
- No cookie modal reproduction.
- No prices, ratings, sale badges, stock, cart, SKU or unsupported performance/certification claims.
- No Frozen, Elsa, Disney, watermarked, Chinese promotional-panel, or AI-generated imagery.
