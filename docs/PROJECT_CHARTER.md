# Project Charter: Glove Factory B2B Website

## Scope

- Project: English B2B website for a China-based manufacturer of wedding, bridal, evening and costume gloves.
- Acquisition: Google organic search first; no assumption of paid acquisition.
- Primary conversion: qualified wholesale, OEM/custom, private-label and sourcing enquiries.
- Phase: Phase 0 only (research, governance and planning).

## Guardrails

- Do not start production web development, create a production domain, database, Supabase project or paid service before explicit approval.
- Do not choose the final English brand name or primary keyword before product-fit and SERP validation.
- Do not turn platform claims, estimates or inferences into confirmed factory facts.
- Keep `main` stable; use a phase branch and checkpoint commit before development.

## Sequence

`Research -> Product/Market Fit -> Keyword & SERP -> SEO Architecture -> Site Architecture -> UX/UI -> Technical Architecture -> Development`

## Phase 0 exit criteria

The team has a source inventory, facts/assumptions register, factory product map, evidence CSV, B2B SEO adaptation, infrastructure register, factory questions, seed keyword set and a SERP research plan. Phase 0 ends here; development is explicitly out of scope.
